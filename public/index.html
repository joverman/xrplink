How It Works

Three steps from transaction hash to verified receipt

1

Submit a Transaction

Paste any XRP transaction hash — whether from a wallet, exchange, or block explorer. No account needed.

2

We Attest It

Our service submits the transaction to Flare's FDC protocol, where it's independently verified by a decentralized network of attestation providers.

3

Get Your Receipt

A shareable, printable receipt with a cryptographic Merkle proof. Anyone can independently verify it on-chain — no trust required.

Use Cases

🏛️

Compliance Records

Regulated businesses can produce court-admissible, cryptographically verifiable proof of any XRP payment. Satisfy FinCEN, FCA, and other regulatory requirements with tamper-evident receipts.

Audit Trails

External auditors can independently verify XRP payment records against the Flare blockchain — no need to trust a centralized API or an exported CSV. Reduce manual verification from hours to seconds.

Merchant Receipts

Businesses accepting XRP payments get professional, verifiable receipts for their accounting. Share a link with your counterparty — they can verify the payment without running any software.

API & Integration

Automate receipt generation from your applications

Verify an XRP Payment

curl -X POST https://xrplink.io/api/v1/verify/xrp-payment \
-H "Content-Type: application/json" \
-H "X-API-Key: sk_live_..." \
-d '{"txHash": "87AD359..."}'

Returns an attestation ID. Proof is ready in ~90 seconds. Check status with GET /api/v1/status/:id.
